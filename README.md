# muduo-learning

通过抄写、注释和重写 muduo 源码，学习 C++ 网络编程与 Reactor 模式。

> 本项目仅用于个人学习。代码基于/抄写自 [chenshuo/muduo](https://github.com/chenshuo/muduo)，
> 版权归原作者所有，遵循其原始许可证。
> 本项目不是 muduo 官方仓库，也不代表原作者。

## 内容

- muduo 源码抄写与注释
- 关键类分析：EventLoop、Channel、Poller、TcpConnection
- 自己实现的 mini-muduo 示例
- 学习笔记与调试记录
